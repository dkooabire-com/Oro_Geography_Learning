# Oro Geography Learning — Android project

A starter native Android app for Ethiopian secondary Geography students (Grades 9–12). It includes sample curriculum notes, a practice quiz with explanations, and schematic diagrams drawn directly in the app so they do not depend on missing online image files.

## Build an APK
1. Install Android Studio on a computer and install Android SDK 35 and JDK 17.
2. Extract this folder.
3. In Android Studio, choose **Open** and select the `OroGeographyLearning_Final` folder.
4. Allow Gradle to sync and download dependencies (internet is needed for the first build).
5. Choose **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. Android Studio will show a link to the generated APK, usually at `app/build/outputs/apk/debug/app-debug.apk`.
7. Transfer that APK to your Android phone and install it. If prompted, allow your file manager to install unknown apps.

## Important
This ZIP is an Android Studio project, not an already compiled APK. This environment does not have the Android SDK/Gradle build environment needed to compile and test an APK. The included notes are starter examples, not a complete copy of the official Ethiopian textbooks. Verify and expand content against your current textbook before classroom use.
